# Helm Product Brief

## Product Name

Helm

## Tagline

Plan. Navigate. Deliver.

## Product Category

Project management command center

## Product Vision

Helm gives project managers one reliable place to initiate, plan, execute, monitor, control, and close projects.

It replaces disconnected spreadsheets, risk registers, meeting notes, action trackers, status reports, and closure documents with one connected project workspace.

## Primary User

The primary user is a project manager responsible for:

* Coordinating project delivery
* Maintaining governance
* Tracking project health
* Managing risks and issues
* Following up on action items
* Communicating with stakeholders
* Guiding the project from initiation through closure

## Secondary Users

* Project sponsors
* Project team members
* Workstream leads
* Stakeholders
* Portfolio managers

## Core User Outcomes

A project manager should be able to:

* Understand project health immediately
* See what needs attention
* Track risks, assumptions, issues, and dependencies
* Assign and follow up on action items
* Record decisions and their context
* Coordinate team members and stakeholders
* Monitor milestones and deliverables
* Prepare project status reports
* Control project changes
* Complete handover and project closure

## Product Positioning

Helm is not simply another task manager.

It is a project command center designed around the complete project lifecycle, from initiation through closure.

## Brand Direction

Helm should feel:

* Professional
* Calm
* Dependable
* Precise
* Structured
* Enterprise-ready
* Clear rather than overwhelming

## Design Philosophy

The interface should help project managers make decisions quickly.

Important information should be easy to find, project health should be visible at a glance, and overdue or high-risk items should be clearly highlighted without creating unnecessary visual noise.

## Initial Product Modules

* Project Overview
* Team and Stakeholders
* Milestones and Deliverables
* RAID Register
* Action Items
* Decision Log
* Status Reporting
* Change Control
* Project Closure
* Lessons Learned
